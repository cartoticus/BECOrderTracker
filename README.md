# BEC Supply Orders

Office supply ordering and tracking for the Great Barrington office.

**Live site:** https://cartoticus.github.io/BECOrderTracker/

- `index.html` — the whole app (single file, no build step). Replace it to update the app.
- Data is **not** stored on this branch. The app saves to `data.json` on the **`supply-data`** branch, which it creates on first sync. Every save there is a commit, so its history doubles as a backup.

Setup, token renewal, backups and troubleshooting are in the app's **How to** tab.
